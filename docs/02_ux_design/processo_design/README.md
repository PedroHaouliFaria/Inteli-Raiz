# Processo de design

Caminho do IBM Enterprise Design Thinking feito pelo Leonardo, com estilo visual Carbon (IBM). A cada etapa foram apresentadas 3 versões e escolhida uma.

> **Leia primeiro:** este processo começou quando a **analista** era a usuária principal. Em 28/10 o grupo passou a colocar o **associado** no centro, com a analista só nas exceções. As entregas vigentes de UX são [D02](../D02_mapa_empatia.md), [D03](../D03_cenario_atual.md), [D06](../D06_persona_e_cenarios.md), [D12](../D12_prototipo_experiencia.md) e [D13](../D13_validacao_melhorias.md).
