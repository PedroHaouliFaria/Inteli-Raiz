## Processo de design

A pasta [processo_design/](processo_design/README.md) guarda as referências de descoberta, do console legado e do laboratório do modelo, além do [glossário](processo_design/glossario.md). As alternativas de telas substituídas foram retiradas da pasta e continuam no histórico Git.

Esse processo começou quando a **analista** era a usuária principal. Cada etapa tem no topo um aviso do que continua valendo; o [glossário](processo_design/glossario.md) já está atualizado para o fluxo do associado.
