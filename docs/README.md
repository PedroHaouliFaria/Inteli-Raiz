## Como a documentação está organizada

- **[documentacao-do-projeto.md](documentacao-do-projeto.md):** a história completa, em 11 seções. É a leitura principal.
- **[tecnologias.md](tecnologias.md):** todas as tecnologias do projeto, incluindo as da IBM (Bob, watsonx.ai, watsonx Orchestrate e Carbon), com o papel de cada uma.
- **[anexos/](anexos/README.md):** o detalhamento e as fontes, separados por assunto: produto, experiência do usuário, sistema, dados e modelo, gestão, evidências e histórico.
- **[anexos/historico/](anexos/historico/):** planos antigos recuperados do Git. Mostram o caminho percorrido, não o estado atual.

Os arquivos `.md` são documentos de texto em Markdown. No GitHub, abra o arquivo para ler a versão formatada. Revisão de conteúdo não equivale a testes com usuários ou comprovação de retorno financeiro.
