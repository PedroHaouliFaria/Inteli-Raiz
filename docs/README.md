Os arquivos `.md` são documentos de texto em Markdown. No GitHub, abra o arquivo para ler a versão formatada. Os anexos guardam o detalhamento e as fontes; a documentação principal organiza a história e explica as decisões. Revisão de conteúdo não equivale a testes com usuários ou comprovação de retorno financeiro.
